# Car Price Prediction

## Overview
This project applies machine learning techniques to predict car prices. It explores both fundamental models and advanced approaches to improve prediction accuracy and feature understanding.

## Project Structure
- `01_baseline_model.ipynb` – Initial model development using basic regression techniques  
- `02_advanced_model.ipynb` – Improved models with feature engineering and hyperparameter tuning  

## Methodology
- Data preprocessing (handling missing values, encoding, scaling)  
- Exploratory data analysis  
- Machine Learning Models (KNN, Decision Tree, Linear Regression)
-  Hyperparameter tuning using GridSearchCV 
- Advanced ML Techniques (AML)
    Automated Feature Selection
    Tree Ensembles (Random Forest, etc.)
    Ensemble of Ensembles
    Feature Importance Analysis
    SHAP (Model Explainability)
    Dimensionality Reduction:
    Linear (PCA)
    Non-linear methods
    Clustering for Feature Engineering 
- Model evaluation 

## Results
- Linear and ensemble models showed strong predictive performance  
- Feature engineering and tuning improved model accuracy  
- Final model selected based on generalisation performance  

## Tools & Technologies
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib, Seaborn
- SHAP (for explainability)

## Future Work
